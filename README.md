# 櫻桃班 親師公告欄

幼幼班櫻桃班的公告網站，資料放在 Google 試算表，網站放在 GitHub Pages。
老師只要改試算表，家長重新整理網頁就會看到新內容，不需要改程式。

## 檔案結構

```
docs/index.html       網站本體（樣式、程式都在這一個檔案）
apps-script/Code.gs   貼到 Google 試算表的 Apps Script（資料中介）
櫻桃班資料表範本.xlsx  Google 試算表範本（不一定要上傳到 GitHub）
```

## 一、建立 Google 試算表

1. 到 Google 雲端硬碟上傳 `櫻桃班資料表範本.xlsx`，按右鍵選「開啟工具 → Google 試算表」，
   再選「檔案 → 儲存為 Google 試算表」。
2. 共用設定維持「限制」（只有老師能開啟），不需要公開。

分頁與欄位（第 1 列欄位名稱不可修改，分頁名稱不可改名）：

| 分頁 | 欄位 |
|---|---|
| 週報 | 週次、起、迄、櫻桃成長記、櫻桃小須知 |
| 兒歌 | 週次、名稱、內容、影片網址 |
| 手指謠 | 週次、名稱、內容、影片網址 |
| 畫廊 | 週次、日期、標題、圖片網址、說明 |
| 繪本 | 週次、書名、作者、封面網址、介紹 |
| 行事曆 | 日期、活動、備註 |
| 須知 | 類別（請假／接送／托藥）、標題、內容 |

週報頁會用「週次」自動把同一週的兒歌、手指謠、照片、繪本放在一起。
該週沒有填寫的項目會自動隱藏。「繪本」分頁若還沒建立，網站照常運作，只是不顯示繪本區。

週報的「起」「迄」填日期（例如 2026/09/21），網站會自動顯示成「9/21（一）至 9/25（五）」。
「起」欄標題寫成「週期」也可以讀取。

## 二、安裝 Apps Script（資料中介）

1. 在試算表選「擴充功能 → Apps Script」。
2. 刪掉編輯器裡原本的內容，貼上 `apps-script/Code.gs` 的全部內容，按儲存。
3. 上方函式選單選 `testRead` 按「執行」，第一次會要求授權：
   選自己的帳號 →「進階」→「前往（不安全）」→「允許」。
   （這是自己寫的程式，Google 沒審核過才會這樣顯示。）
   執行記錄出現試算表資料就代表讀取正常。
4. 右上角「部署 → 新增部署作業」，類型選「網頁應用程式」：
   - 執行身分：我
   - 誰可以存取：所有人
5. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。
   用無痕視窗打開這個網址，看到一串資料（JSON）就成功了。
6. 打開 `docs/index.html`，把網址貼到最上方的 `API_URL`：
   ```js
   const CONFIG = {
     API_URL: 'https://script.google.com/macros/s/……/exec'
   };
   ```

`API_URL` 留空白時，網站會顯示內建的示範資料。

### 注意事項

- 只有 `Code.gs` 裡 `SHEETS` 列出的分頁與欄位會被送出。試算表可以另開分頁或欄位放內部資料，不會外流。
- 改了試算表內容：最多 60 秒後網站就會更新（可調整 `CACHE_SECONDS`）。
- 改了 `Code.gs` 程式：要到「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本 → 部署」，
  網址不變，但不這樣做會一直跑舊程式。
- 使用機構的 Google Workspace 帳號時，「誰可以存取」可能沒有「所有人」選項，需改用個人帳號或請管理員開放。
- 照片、封面若放在 Google 雲端硬碟，那些圖片檔仍需設為「知道連結的任何人可檢視」才能顯示。

## 三、發布到 GitHub Pages

1. 在 GitHub 建立新的 repository（公開），把整個資料夾推上去：
   ```
   git init
   git add .
   git commit -m "115櫻桃班公告欄"
   git branch -M main
   git remote add origin https://github.com/<帳號>/<repo>.git
   git push -u origin main
   ```
2. 到 repo 的「Settings → Pages」，Source 選「Deploy from a branch」，
   Branch 選 `main`、資料夾選 `/docs`，按 Save。
3. 約 1～2 分鐘後，同一頁上方會顯示網址：`https://<帳號>.github.io/<repo>/`

免費帳號只有公開 repo 能使用 GitHub Pages，且網站一律公開。

## 照片與影片

- 照片：上傳到 Google 雲端硬碟，共用設為「知道連結的任何人可檢視」，把分享連結貼到「圖片網址」，
  網站會自動轉成可顯示的圖片。也可以直接貼任何圖片網址。
- 影片：貼 YouTube 連結，網頁會顯示「播放影片」按鈕，按下才載入影片。
- 網站上的照片是公開連結，請先確認家長同意孩子照片上網。
